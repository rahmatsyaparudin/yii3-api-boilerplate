# ColumnContract

## Kontrak kolom standar untuk migration

`App\Shared\Core\Enums\ColumnContract` adalah titik pusat untuk
**default value** dan **comment** kolom-kolom konvensional (`id`,
`status`, `detail_info`, `origin_id`, `sync_flag`, `sync_mdb`,
`lock_version`). Tujuannya: semua migration konsisten, self-documenting,
dan kalau konvensi berubah cukup edit satu file.

### Cara pakai

```php
use App\Shared\Core\Enums\ColumnContract;

$b->createTable(self::TABLE_NAME, [
    'id'          => $cb::integer()->notNull()->extra(ColumnContract::PG_PRIMARY_KEY_IDENTITY),
    'name'        => $cb::string(255)->notNull(),
    'status'      => $cb::smallint()->notNull()->defaultValue(ColumnContract::statusDefault())->comment(ColumnContract::statusComment()),
    'detail_info' => $cb::json()->notNull()->defaultValue(ColumnContract::DETAIL_INFO_DEFAULT)->comment(ColumnContract::DETAIL_INFO_COMMENT),
    'origin_id'    => $cb::integer()->null()->comment(ColumnContract::ORIGIN_ID_COMMENT),
    'sync_flag'    => $cb::smallint()->null()->defaultValue(ColumnContract::SYNC_FLAG_DEFAULT)->comment(ColumnContract::SYNC_FLAG_COMMENT),
    'sync_mdb'     => $cb::smallint()->null()->comment(ColumnContract::SYNC_MDB_COMMENT),
    'lock_version' => $cb::integer()->notNull()->defaultValue(ColumnContract::LOCK_VERSION_DEFAULT)->comment(ColumnContract::LOCK_VERSION_COMMENT),
]);
```

### API — Defaults

| Konstanta / Method | Isi |
|---|---|
| `PG_PRIMARY_KEY_IDENTITY` | `'PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY'` — clause `extra()` untuk kolom `id` di PostgreSQL. |
| `MYSQL_TIMESTAMP_AUTO_UPDATE` | `'DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP'` — clause `extra()` untuk kolom timestamp di MySQL (auto set saat insert + refresh saat update, cocok untuk `updated_at`). |
| `MYSQL_INNODB_COLLATION` | `'CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci ENGINE=InnoDB'` — table-level options untuk `CREATE TABLE` di MySQL (charset, collation, engine). |
| `statusDefault(string $status = 'draft')` | Nilai default kolom `status`. Tanpa argumen → `DRAFT` (2). Terima nama status *case-insensitive*, mis. `statusDefault('active')`. Lempar `InvalidArgumentException` untuk nama tak dikenal. |
| `DETAIL_INFO_DEFAULT` | Payload awal `detail_info`: `['change_log' => ['created_at' => null, 'created_by' => null, 'updated_at' => null, 'updated_by' => null, 'deleted_at' => null, 'deleted_by' => null]]`. |
| `SYNC_FLAG_DEFAULT` | `1` (not synced). |
| `LOCK_VERSION_DEFAULT` | `1` (optimistic locking). |

### API — Comments

| Method | Teks comment |
|---|---|
| `statusComment()` | Legend status dari `RecordStatus::describe()` — `"0: Inactive, 1: Active, 2: Draft, ..."`. Selalu sinkron dengan enum. Tetap method karena hasilnya di-generate. |
| `DETAIL_INFO_COMMENT` | Struktur `change_log` + catatan key spesifik modul. |
| `ORIGIN_ID_COMMENT` | `'origin instance id where the record comes from or goes to'` |
| `SYNC_FLAG_COMMENT` | `'null: synced, 1: not synced'` |
| `SYNC_MDB_COMMENT` | `'null: sync to MDB, 1: not sync to MDB'` |
| `LOCK_VERSION_COMMENT` | `'Optimistic locking version'` |

### Menyimpang dari konvensi

Kalau sebuah kolom sengaja beda (mis. `service_tokens.status` mulai dari
`ACTIVE`, bukan `DRAFT`), tetap lewat `ColumnContract` supaya intent-nya
kelihatan eksplisit:

```php
'status' => $cb::smallint()->notNull()->defaultValue(ColumnContract::statusDefault('active'))->comment(ColumnContract::statusComment()),
```

### Menambah konvensi baru

`ColumnContract` ada di `src/Shared/Core/` (frozen, di-sync via
`composer skeleton:update`) — penambahan kolom konvensional baru
(`xxxDefault()` / `XXX_DEFAULT` / `xxxComment()`) dilakukan di
boilerplate upstream, bukan patch lokal.
