# v1.2.0 — 2026-10-21

### Added
- **`DatabaseCache`** (`src/Infrastructure/Core/Cache/`) — managed cache
  untuk data DB (`remember`/`rememberForever`/`refresh`/`get`/`set`/
  `has`/`forget`/`forgetMultiple`/`clear`) atas PSR-16, dengan degradasi
  aman (backend mati/disabled → callback langsung, `get` → default).
  Wiring `config/common/di/cache-di.php`, params `app/cache`
  (`app.cache.*` env), driver `auto|redis|file|psr` dengan probe Redis
  + fallback `FileCache @runtime/cache/db`. `docs-guide/27-database-cache.md`.
- **Modul System — Cache** — `POST /v1/system/cache/purge` untuk purge
  semua cache yang tergenerate (PSR-16, Yii cache, FileCache
  `@runtime/cache` + schema cache, Redis `flushDB`, `DatabaseCache`,
  OPcache, stat cache). File: `src/Api/V1/System/Cache/`,
  `src/Application/System/Cache/`, `docs-guide/26-system-cache.md`.
- **Managed-block sync** — `scripts/managed/{ManagedBlockSync,
  routes-system.block,access-system.block}.php`; `skeleton:update`
  men-sync blok marker di `config/common/routes.php` dan
  `config/common/access.php` secara idempotent.
- `skeleton-update.php` — `copySystemModule()`: modul System
  (`src/{Api/V1,Application,Domain}/System`) kini disalin tiap update.

### Changed
- Modul System (`src/{Api/V1,Application,Domain}/System`) kini disalin
  oleh `skeleton:update` — skeleton-managed/frozen, bukan contoh
  sekali-salin.
- `redis.default.enabled` — default `params-core` kini `false`
  (sebelumnya `true`): Redis opt-in, `driver=auto` langsung pakai
  FileCache bila flag tidak diset.
- `config/common/di/middleware-di.php`,
  `src/Presentation/Core/Http/Middleware/ServiceTokenAuthMiddleware.php`,
  `config/common/routes.php`, `config/common/repository.php` —
  referensi `use` mengikuti namespace baru modul.
- `docs-guide/{03-project-structure-guide,24-skeleton-guide,26-system-cache}.md`
  — struktur direktori + tabel env diperbarui.
- Format versi changelog app memakai prefix `v` per-file
  (`changelog/vX.Y.Z.md`), terpisah dari versi skeleton.

### Renamed
- Modul Service Token — folder `Token` → `ServiceToken` di ketiga layer
  agar konsisten dengan route `/v1/system/service-token/*`:
  `src/Api/V1/System/ServiceToken/`,
  `src/Application/System/ServiceToken/`,
  `src/Domain/System/ServiceToken/` (namespace
  `App\...\System\Token` → `App\...\System\ServiceToken`).

### Catatan migrasi (project konsumen)
- Yang sudah menyalin modul `System` di rilis skeleton `v1.3.0` harus
  me-rename folder `Token` → `ServiceToken` di project-nya (atau
  re-copy via `skeleton:copy-examples`) setelah `skeleton:update` —
  Core middleware kini mereferensikan namespace baru.
