# v1.2.2 — 2026-11-18

### Ditambahkan
- **Marker `skeleton-source-only` di semua `AGENTS.md`** (10 file) —
  blok `<!-- skeleton-source-only:start/end -->` memberi tahu agent
  bahwa repo ini adalah sumber skeleton dan `Core/` editable di sini;
  rules frozen di bawahnya berlaku untuk project konsumen. Blok
  di-strip otomatis saat sync sehingga konsumen hanya menerima
  rules yang relevan.

### Diperbaiki
- `skeleton-update.php` `copyMessageFiles()` — file root-level di
  `resources/messages/` (mis. `AGENTS.md`) kini ikut tersalin;
  sebelumnya ter-skip karena loop hanya membaca subdirectory bahasa.
  `app.php` tetap dilindungi.
- `copyDirectory()` — no-op saat `source === target`, mencegah
  strip/copy in-place bila installer dijalankan di dalam repo sumber.
- Helper privat baru `stripSourceOnlyBlocks()` dipakai di semua jalur
  copy (`copyProtectionFiles`, `copyDirectory`, `copyMessageFiles`).

### Catatan migrasi (project konsumen)
- Tidak ada aksi — jalankan `composer skeleton:update` seperti biasa;
  `AGENTS.md` akan ter-update tanpa blok source-only.
